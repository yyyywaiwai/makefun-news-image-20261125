This is a newspaper front page for 25 November 2026, drawn as a
single 1024×1024 picture (`entry.png`).

The headline story is Ukraine's admission that it struck a Russian
cargo ship in the Gulf of Finland — President Zelenskiy confirmed
the attack himself. Below it, six more stories from the day: a
Houthi missile hit on Riyadh's tallest tower, a US jury finding
Huawei guilty on 10 of 12 counts, the Nasdaq sliding 1.5% as the
AI rally reversed and Nvidia fell about 6%, Pakistan's first
astronaut riding China's Shenzhou-24 to orbit, an Israeli strike
in Gaza City that killed a Hamas internal-security chief, and a
magnitude 5.6 earthquake in eastern Nepal.

`main.py` is the entry point. It copies `entry.png` into the
grader's output directory and verifies the copy by size and SHA-256.
Python 3, standard library only — no network, no randomness, and
every run produces the same bytes.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
